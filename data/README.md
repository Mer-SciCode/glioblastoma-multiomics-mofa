The datasets used in this project were obtained from LinkedOmics.
aw datasets are not included in this repository due to file size and data distribution considerations.
The analysis scripts describe the preprocessing and analysis workflow used in the original project.

Citation:
Suhas V Vasaikar, Peter Straub, Jing Wang, Bing Zhang, LinkedOmics: analyzing multi-omics data within and across 32 cancer types, Nucleic Acids Research, Volume 46, Issue D1, 4 January 2018, Pages D956–D963.https://doi.org/10.1093/nar/gkx1090
